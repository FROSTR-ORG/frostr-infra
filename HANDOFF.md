  active plan is bifrost-rs(+vendored wasm) → igloo-shared → igloo-ui → igloo-pwa → igloo-chrome →
  igloo-paper → parent pointer bump; the igloo-paper 67-file diff should be its own checkpoint ("Paper
  export refresh: Alerts contents/contract + SVG serialization normalization"). Keep **pre-existing parent
  WIP out** of feature commits: `test/igloo-pwa/specs/app-shell.spec.ts`, `rotation-create.spec.ts`,
  `test/scripts/test-run-sh.sh`, plus `repos/bifrost-rs` (already-dirty WIP that the recover binding lives in).
- **igloo-chrome cannot be fully verified locally.** It has **pre-existing** igloo-ui API drift
  (`AppHeader` `title`/`subtitle`, missing `OperatorMethodPermissionOverride`/`OperatorPolicyOverrideValue`
  exports, `StoredProfileCardModel.shortId`, `PermissionsPanel`/`Signer` prop shapes) and a vitest
  `localStorage.clear is not a function` env failure across all 24 test files. Neither is caused by this
  work; the recover-from-share removal there is symbol-clean (tsc shows no errors referencing removed
  symbols). Confirm chrome in CI.
- **`CreateFlowProfileSetup` API changed** (WS2): it now takes `relays: string[]` + `onRelaysChange` +
  `onPingRelay` (not the old `relayUrls` string / `onRelayUrlsChange`). The store still stores
  `relayUrls` as a newline string; App.tsx converts (`relays.join('\n')`). Don't reintroduce the string API.
- **`finishSetup` is the security-sensitive moment** (WS3): never persist plaintext secrets; clear
  `generatedKeyset`/`unlockPhrase` and stop the runtime before returning to the lock screen. The profile is
  already persisted at the Save-Profile step (`acceptGeneratedProfile`, runtime auto-starts); Finish Setup
  captures the *updated* snapshot (peer/nonce negotiated during distribution) and locks.
- **"Onboarded" has no signal today** except via the new event (WS3d) — there is no existing peer-onboarded
  callback; the nonce-pool poll was the rejected alternative. WHY the real event was chosen: it's clean/fast
  and fires when the distributor *serves* an onboard response (acceptable proxy; a true ack would need a new
  message type, out of scope).
- **Paper MCP edit access** needed a Paper Desktop restart once this session to grant edit access; if MCP
  calls return "Edit access is required," ask the user to restart Paper Desktop.
- **WASM rebuild needs escalation** (`wasm-opt`) per the repo's own FOLLOWUPS — expect to run it with
  `dangerouslyDisableSandbox` or hand the exact commands to the user.
